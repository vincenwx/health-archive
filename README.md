# 家庭健康档案

家庭医疗单据的存储、查询、分析与提醒。纯本地 PWA：数据只保存在你自己的设备浏览器里，无服务器、无账号。

**当前进度**：v0.2.0（M2 AI 识别版）

## 功能

### 已完成（M1 + M2）

- 家庭多成员档案：姓名、关系、性别、出生日期、血型、过敏史
- 就诊记录：门诊 / 住院 / 体检 / 疫苗 / 自购，医院、科室、医生、诊断、经过
- 单据归档：拍照 / 相册 / PDF 上传（大图自动压缩），15 种单据类型，金额（总金额 / 自付）
- **AI 识别**（M2）：拍照后一键识别，自动提取医院、日期、科室、诊断、金额、药品、化验指标，人工核对后保存；支持智谱 GLM 等兼容接口，Key 只存本机
- **自动归就诊**（M2）：保存单据时按「成员 + 日期 + 医院」自动归入或创建就诊记录
- 单据 ↔ 就诊双向关联
- 检索：关键词 + 成员 + 单据类型筛选
- 访问口令：PBKDF2 加盐哈希，无操作自动锁定
- 备份：一键导出 zip 整包（数据+原文件），导入恢复（覆盖式）
- PWA：可安装到手机主屏幕，安装后离线可用

### 规划中

- M3：提醒中心（用药 / 复诊 / 复查 / 疫苗体检）+ 系统日历导出；处方识别结果一键生成用药计划
- M4：统计分析（花费、指标趋势、就诊时间线，区分体检与就诊）
- M5：自然语言问答（问档案，答附单据溯源）
- M6：自动备份增强、细节打磨

## 技术栈

Vite + React 19 + TypeScript + Tailwind CSS 4 + Dexie (IndexedDB) + fflate + vite-plugin-pwa

## 开发

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（热更新）
npm run build      # 类型检查 + 构建到 dist/
npm run preview    # 本地预览构建产物 http://localhost:4173
npm run icons      # 重新生成 PWA 图标
```

## 数据与隐私

- 所有数据（含单据照片）存储在**当前设备的浏览器 IndexedDB** 中，换浏览器/换设备不共享，多设备需用备份文件迁移
- 请务必「添加到主屏幕」后使用（iPhone 的 Safari 普通标签页 7 天不用可能清理网站数据）
- 养成每月导出备份的习惯（设置 → 备份与恢复）
- 访问口令用于防止随手翻看，不等于整库加密；备份包请自行妥善保管
