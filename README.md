# 家庭健康档案

家庭医疗单据的存储、查询、分析与提醒。纯本地 PWA：数据只保存在你自己的设备浏览器里，无服务器、无账号。

**当前版本**：v1.0.0（全功能正式版） · **线上地址**：https://vincenwx.github.io/health-archive/

## 功能总览

- **家庭多成员档案**：姓名、关系、性别、出生日期（直接输入）、血型、过敏史
- **就诊与单据**：门诊/住院/体检/疫苗/自购五类就诊记录；单据拍照/相册/PDF 上传（一次最多 20 张、自动压缩、按内容自动命名如"糖尿病门诊病历260910.jpg"）；单据 ↔ 就诊双向关联
- **AI 识别**：自动提取单据类型、日期、医院、科室、医生、诊断、金额、药品、化验指标、患者姓名（自动匹配成员）；**多日期单据自动拆分归档**；按"成员+日期+医院+科室"自动归入或创建就诊记录
- **AI 解读**：单张单据解读 + 就诊级综合解读，归纳整理为概览/诊断检查/用药方案/医嘱/总结与建议五段，末尾附具体建议
- **提醒中心**：用药计划（从处方识别结果一键生成）、复诊/复查/疫苗体检提醒、今日服药打卡、过期标红；**导出系统日历(.ics)**——写入手机日历由系统准点推送，iPhone/鸿蒙/安卓通吃
- **统计分析**：医疗花费（年/月柱状、自付占比、类别与医院分布，体检与就诊分开）；**健康指标趋势**（同名指标跨报告自动积累、异常点标红、参考区带、**AI 趋势分析与建议**）；按成员的就诊时间线
- **自然语言问答**：对话式问档案（"今年花了多少""最近血糖趋势"），多轮追问，回答附**可点击的相关记录链接**直达详情
- **安全与备份**：访问口令（PBKDF2，自动锁定）；一键备份导出/导入（zip 整包含原图）；超 30 天未备份首页提醒；电脑端**自动备份**到指定文件夹
- **PWA**：添加到主屏幕，安装后离线可用

## 技术栈

Vite + React 19 + TypeScript + Tailwind CSS 3 + Dexie (IndexedDB) + fflate + vite-plugin-pwa

## 开发与部署

```bash
npm install
npm run dev        # 开发
npm run build      # 构建到 dist/
npm run preview    # 本地预览
npm run icons      # 重新生成 PWA 图标
```

**线上部署（GitHub Pages）**：仓库 `vincenwx/health-archive`（公开），`main` 分支为源码，`gh-pages` 分支为构建产物。更新流程：`npm run build` 后把 `dist/` 内容提交并推送到 `gh-pages` 分支即可，一分钟生效。

## 数据与隐私

- 所有数据（含照片）只存在**当前设备的浏览器 IndexedDB** 中；换设备用「导出备份 → 导入恢复」迁移
- AI 识别/解读/分析/问答会把单据图片或**文字档案摘要**发送给你在设置中配置的模型服务商（默认智谱 GLM）；不配置则全部手动，数据不出设备。API Key 只存本机
- 请「添加到主屏幕」后使用，并养成定期备份的习惯（应用会自动提醒）
- 访问口令用于防止随手翻看，不等于整库加密
